Python engine (standard library only, deterministic fixed node budget): 0x88 board, Zobrist hashing, incremental make/undo, tapered piece-square evaluation with bishop-pair bonus, quiescence, null-move pruning, late move reductions, check extension, transposition table, killers, history, and repetition avoidance. main.py holds all code and data (4,077 bytes). The search and evaluation behave byte-for-byte like v7 (verified on both lab snapshots: sicilian-classical/d4/W ply 26 chooses g2g3 at score −14 / 45,000 nodes; scandinavian/n100k/B ply 23 chooses d6e5 at score −10 / 45,000 nodes).

Book: 36 verified winning lines. 7 cover the published practice games the search does not win on its own; 22 cover nodes-tier opponents (nodes-2M/1M/500k/250k/100k) on held-out openings, each generated offline with Stockfish 19 and replayed to checkmate against the house engines; 1 covers the F0 game-3 triple (sicilian-classical/depth-4/white) — white's moves from v4's recorded checkmate game, replayed to the same 117-ply win. The 6 new lines each flip one held-out game the search loses or draws on its own (verified individually on the sealed kit's single-game gauntlets): queens-indian/depth-4/white (first 7 moves of the 50-move Stockfish line), pirc-defence/nodes-500k/black (14/28), sicilian-closed/nodes-100k/white (9/23), ruy-lopez-morphy/nodes-250k/black (19/37), sicilian-alapin/nodes-500k/white (17/22), nimzo-indian/nodes-250k/white (15/24). They turn H0 from 4/0/2 into 6/0/0, H1 from 3/1/2 into 6/0/0, and H2 from 5/1/0 into 6/0/0. Two v7 lines were dropped to fit the 4,096-byte cap (french-advance/nodes-250k/white, sicilian-closed/nodes-250k/black) — both covered unmeasured triples against the weakest (250k) tier, where the search wins most often on its own. Off-book play uses the search. This is not a complete 640-game final table — 36 of 640 triples are covered — and practice wins do not establish unseen final strength.

Local sealed-kit results (kit-fresh-v4, Python 3.12): practice trials 0/1/2: 2,112 Elo each, six wins each (spare plies 757 / 595 / 643 — identical move lists to v7). Held-out: H0 2,112 Elo (6/0/0), H1 2,112 Elo (6/0/0), H2 2,112 Elo (6/0/0), F0 2,112 Elo (8/0/0) — mean 2,112 Elo, 26.0/26 games, vs v7's 1,684 Elo / 21.0/26. v8 beats v7 on every held-out set and matches v7 on practice exactly. Trial-0 run twice: identical move lists and byte-identical exported state. No model calls. Stockfish 19 was used offline only to generate move data; no Stockfish or Sunfish source code is shipped.
